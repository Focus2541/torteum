# ต่อเติมห้อง ผนังเบา

- `video.html` คลิปสอนแบบภาพเคลื่อนไหว 10 คลิป มีเสียงพูดภาษาไทย
- `guide.html` คู่มือมือใหม่ พร้อมภาพประกอบ
- `design.html` ออกแบบโครงผนัง ระยะเสา จุดพุก รายการตัดเหล็ก
- `counter.html` ออกแบบเคาน์เตอร์ผนังเบา (ตรง/L/U) พร้อมท็อปและราคา
- `wardrobe.html` ออกแบบตู้เสื้อผ้าบิวท์อิน รายการตัดแผ่นส่งร้าน แผนวางแผ่น และราคา
- `furniture.html` ตู้โครงเหล็ก + ผ้าม่าน และโต๊ะเครื่องแป้งกล่อง
- `preview.html` ภาพห้องเสร็จ 3D (three.js ใน vendor/)
- `calc.html` คำนวณค่าใช้จ่าย + แผนซื้อตามงบ (จำเป็น → ควรมี → ทีหลังได้)

เปิดใช้ผ่าน GitHub Pages: https://focus2541.github.io/torteum/
