น้ำตาล = มีไฟฟ้า = ไฟกลับเขียวเหลือง = ลงดิน
  1. ปิดเบรกเกอร์ แล้ววัดก่อนจับ ไขควงวัดไฟต้องไม่ติด
  2. สีตรงตัวอักษร L = น้ำตาล · N = ฟ้า · ⏚ = เขียวเหลือง
  3. สวิตช์กินแต่น้ำตาล สายฟ้าไม่ผ่านสวิตช์เด็ดขาด

ฝึกจำ: แตะช่องเพื่อเลือกสีสาย แล้วกดตรวจ

สวิตช์หลายจุด: จำเป็นประโยค

สวิตช์ 2 จุด (บันไดบน-ล่าง) ใช้สวิตช์ 2 ทาง 2 ตัว แต่ละตัวมี 3 ขา: COM, 1, 2

"COM แรกรับไฟ · COM หลังส่งหลอด · 1 ต่อ 1 · 2 ต่อ 2"

สวิตช์ 3–4 จุด หัวกับท้ายเหมือนข้างบน แล้วเอา "สวิตช์กลางทาง" (4 ขา) ไปคั่นสาย 1 กับ 2

"เข้าซ้าย 2 เส้น ออกขวา 2 เส้น" · 3 จุดใส่ 1 ตัว · 4 จุดใส่ 2 ตัว

อยากเห็นว่าทำไมถึงต้องต่อแบบนี้ ดูภาพจำลองแบบละเอียดด้านล่าง

ตั้งแต่เมนลงมา: เสาไฟ → มิเตอร์ → ตู้ → ทุกจุดในบ้าน

แตะเมน ลูกย่อย หรือเครื่องใช้ในภาพเพื่อเปิด/ปิด แล้วดูว่ามิเตอร์หมุนแค่ไหน และส่วนไหนของบ้านดับ

จำลำดับไฟ

  1. เสาไฟ → มิเตอร์ เป็นของการไฟฟ้า ห้ามแตะ
  2. มิเตอร์ → เมนเบรกเกอร์ สายเส้นนี้มีไฟตลอด แม้ปิดเมนแล้ว
  3. เมน → บัสบาร์ → ลูกย่อย ลูกย่อย 1 ตัว = 1 วงจร (ไฟแสงสว่าง / ปลั๊ก / เครื่องทำน้ำอุ่น / แอร์)
  4. บาร์ N รวมสายฟ้าทุกวงจร · บาร์ G รวมสายดินทุกวงจร แล้วลงหลักดิน
  5. ต่อ N กับ G เข้าหากันที่ตู้เมนจุดเดียวเท่านั้น

หน้างานจริง: เซฟตี้เบรกเกอร์ + สวิตช์ + เต้ารับ + หลอดไฟ

มองจากด้านหลังหน้ากาก แบบเดียวกับชุดปลั๊กประกอบทั่วไป ทำทีละขั้น สายที่กำลังต่อจะเป็นเส้นหนากะพริบ

ตำแหน่งขั้วจริงแต่ละยี่ห้อต่างกัน ให้ดูตัวอักษร L, N, ⏚ ที่พิมพ์ไว้หลังโมดูลเสมอ

ต่อภายในชุดปลั๊ก/สวิตช์สำเร็จ

มองจากด้านหลังหน้ากาก ชุดสำเร็จส่วนใหญ่ "ไม่วายสาย" มาให้ เราต้องจั๊มป์สายระหว่างโมดูลเอง กด "ถัดไป" เพื่อดูทีละสาย

ตำแหน่งขั้วแต่ละยี่ห้อต่างกัน ให้ดูตัวอักษร L, N, ⏚ ที่พิมพ์ไว้หลังโมดูลจริง · ขั้วหนึ่งมี 2 รู: รูแรกรับสายเข้า รูที่สองใช้จั๊มป์ต่อ · สายจั๊มป์ใช้ขนาดเดียวกับสายเมนของวงจร

สีสายและหน้าที่
  • L (น้ำตาล) สายที่มีแรงดัน 230 V แตะแล้วโดนไฟดูด
  • N (ฟ้า) ทางกลับของกระแส ปกติแรงดันใกล้ 0 แต่ถ้าวงจรต่อผิดก็มีไฟได้ ห้ามประมาท
  • G (เขียวแถบเหลือง) สายดิน ปกติไม่มีกระแส มีไว้พาไฟรั่วลงดินให้เบรกเกอร์ตัด

สีตามมาตรฐานสายไฟ มอก. 11-2553 · บ้านเก่าอาจเป็นสีดำ/เทา ต้องวัดก่อนเสมอ

กฎหลัก 6 ข้อ
  1. สวิตช์ต้องตัด สาย L เสมอ ไม่ใช่สาย N
  2. เต้ารับต้องเป็นแบบ 3 รู และต่อสายดินจริงไปถึงหลักดิน
  3. แยกวงจรแสงสว่างกับเต้ารับ ไฟปลั๊กตัด ไฟห้องยังสว่าง
  4. เครื่องใช้กำลังสูง เช่น แอร์ เครื่องทำน้ำอุ่น ให้มีวงจรของตัวเอง
  5. ต่อ N กับ G ร่วมกันได้ที่ตู้เมนจุดเดียวเท่านั้น ห้ามไปต่อที่ปลั๊กหรือที่อื่น

สวิตช์สองทางทำงานอย่างไร

สวิตช์สองทางมี 3 ขั้ว: ขั้วกลาง (COM) และขั้วเลือก 2 ขั้ว สายระหว่างสวิตช์ 2 ตัวเรียกว่า "สายวิ่ง" มี 2 เส้น หลอดจะติดเมื่อก้านของทั้งสองตัวชี้ไปที่สายวิ่งเส้นเดียวกัน กดตัวไหนก็สลับสถานะได้ ลองกด SW-A กับ SW-B ด้านบนดู

ต่อ L เข้าขั้ว COM ของตัวแรก และขั้ว COM ของตัวที่สองไปหาหลอด ส่วนสาย N ไปหาหลอดตรงๆ

ขั้นตอนความปลอดภัยก่อนลงมือ
  1. ปิดเมนเบรกเกอร์ (ไม่ใช่แค่ปิดสวิตช์) แล้วแขวนป้าย "กำลังซ่อม ห้ามเปิด"
  2. ทดสอบไขควงวัดไฟหรือมัลติมิเตอร์กับจุดที่รู้ว่ามีไฟก่อน แล้วค่อยวัดจุดที่จะทำงาน
  3. วัดทุกเส้น ทั้ง L, N และ G
  4. ใช้เครื่องมือด้ามฉนวน ยืนบนพื้นแห้ง ใส่รองเท้า
  5. ต่อสายด้วยขั้วต่อหรือ wire nut ขันให้แน่น ห้ามพันเทปอย่างเดียว ห้ามต่อสายนอกกล่อง
  6. เสร็จแล้วกดปุ่ม Test ของ RCBO ให้ตัดได้จริง และกดซ้ำเดือนละครั้ง
